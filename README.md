# React Assignments Repository

A comprehensive collection of production-quality React applications demonstrating component design, unidirectional data flow, deep state management, external REST APIs, enterprise e-commerce with a custom PC builder, and multi-page single-page applications with React Router and JWT authentication.

## 🛠️ Quick Start Guide

Each assignment is a standalone project with its own `package.json` and dependency tree.

To run any assignment locally:

```bash
# 1. Clone the repository
git clone https://github.com/aniruddhakar07/react-assignments.git
cd react-assignments

# 2. Navigate into any assignment folder, e.g., Assignment 5:
cd Assignment_5_Online_shopping_cart

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev     # (or 'npm start' for Assignment 3)
```

Refer to each assignment's individual `README.md` for complete feature breakdowns, step-by-step usage instructions, and configuration options.
